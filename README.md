# 小压子本地网页

双击 `start-xiao-yazi.cmd` 启动，然后访问：

```text
http://127.0.0.1:8765/
```

处理和 TXT 检查全部在本机完成，不调用模型或 OpenAI API，不消耗 token。

## 使用

1. 设置目标文件大小百分比。
2. 选择文件、选择文件夹、拖放文件夹，或粘贴剪贴板图片。
3. 点击“开始处理”。
4. 在页面内查看每个文件和 TXT 的处理结果。
5. 点击“保存到指定文件夹”，授权 Chrome 或 Edge 写入目标目录；也可以直接下载 ZIP。

结果不会覆盖目标目录中的同名文件；同名文件会自动追加 `-2`、`-3`。ZIP 只包含处理后的图片并保持目录结构。图片保持像素尺寸、透明度和 GIF 动画帧，TXT 只读检查且不会保存到图片结果目录或 ZIP。

关闭标题为 `Xiao Yazi Local` 的最小化窗口即可停止服务。再次使用时重新双击启动脚本。

## 免费服务器部署

项目包含 `render.yaml`，可作为 Render Blueprint 部署。部署时必须设置 `APP_PASSWORD`；访问网页时用户名可任意填写，密码使用该环境变量的值。远程版会把选中的文件上传到服务器处理，任务临时文件会自动清理。
